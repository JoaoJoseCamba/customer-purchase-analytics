# 🧠 Customer Purchase Analytics

A data‑driven project designed to analyze customer purchasing behavior and uncover actionable insights for business decision‑making.

---

## 📊 Overview

This repository contains a Jupyter Notebook (`customer_analysis.ipynb`) that explores customer purchase patterns using Python.  
It demonstrates how to:

- Clean and preprocess transactional data
- Perform exploratory data analysis (EDA)
- Visualize trends and correlations
- Identify key factors influencing customer spending
